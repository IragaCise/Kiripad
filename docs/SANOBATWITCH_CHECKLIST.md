# サノバウィッチ 初回診断チェックリスト

KiriPad Phase 1をiPadに入れたら、ゲームフォルダを選択して以下だけ記録してください。
ゲーム本体ファイルを共有する必要はありません。

- `Kirikiri系の可能性`
- `data.xp3` の有無
- `startup.tjs` の有無
- XP3/TJS/KS/DLL/TPMの個数
- 「ネイティブプラグイン候補」に表示された **ファイル名だけ**
- 動画ファイル数
- 警告一覧

## Phase 2で欲しいログ

エンジンを接続した後は、起動失敗時に以下を自動記録する予定です。

- 最後にロードしたTJSファイル
- 未実装クラス/メソッド名
- プラグインロード要求名
- 例外メッセージ
- レンダラ初期化結果
- オーディオ初期化結果

この情報だけで互換層を追加できる設計にします。
